## 📖 عن المشروع

برنامج عربي بالكامل لاستخراج وإنشاء جلسات Pyrogram لتلجرام. يسمح لك بإنشاء جلسة نصية (Session String) تستخدم لتشغيل الحسابات البرمجياً.

## ✨ المميزات

- ✅ واجهة عربية بالكامل
- 🎨 ألوان جميلة وسهلة القراءة
- 🔒 آمن تماماً (لا يتم حفظ البيانات)
- 💾 حفظ الجلسة في ملف نصي
- 🧪 اختبار الجلسة بعد إنشائها

## 📋 المتطلبات

- Python 3.7 أو أحدث
- مكتبة Pyrogram
- API ID و API Hash من [my.telegram.org](https://my.telegram.org)

```bash
# استنساخ المشروع
